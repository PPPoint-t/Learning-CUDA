# Triton Notes

这里记录你在学习 `Triton-Puzzles` 和后续实现 Triton 算子时的笔记。

建议一开始按 puzzle 编号或主题拆文件，例如：

- `puzzle-01-basics.md`
- `puzzle-02-mask-and-load-store.md`
- `puzzle-03-program-id-and-grid.md`
- `mapping-to-vector-add.md`
- `mapping-to-softmax.md`

建议每份笔记都回答这几个问题：

- 这个 puzzle 的核心语法点是什么
- 它和 CUDA 里的哪种写法最像
- 它能迁移到本仓库的哪个算子
- 哪些地方以后容易写错
